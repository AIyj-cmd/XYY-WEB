# 56xyy.com 原生 Nginx 本地候选

`nginx-56xyy-native.conf` 是 **本地候选，尚未部署**。它从 2026-10-23 只读取得的
`8.138.148.179` 原生 Nginx 主配置派生；不是站点 include，也不适用于历史 Docker
模板 `deploy/nginx-56xyy.conf` 或其安装脚本。

本次仅调整三处共享 443 监听的 HTTP/2 参数，以及主域和 www 域的 HSTS 时长：

- 三处均使用 `listen 443 ssl http2`，保留默认监听的 `default_server`。
- `56xyy.com` 和 `www.56xyy.com` 的 HTTPS 响应继续使用 `always`，包括 www 重定向和错误响应。
- HSTS 从一天 `86400` 增至初阶段七天 `604800`。IP/default 主机不新增 HSTS。
- HTTP 80 跳转、ACME、证书路径、应用端口 `50031`、CMS 端口 `8055`、代理头、超时、请求限制等保持快照原值。

## 后续上线条件

本轮本地测试不能代替真实服务器验证。未来部署前需比对最新生产配置，确认没有快照后的变更，
并核对实际 `nginx -V` 版本、`--with-http_v2_module`、TLS/ALPN 支持和证书路径。
候选采用旧版也支持的 `listen ... ssl http2` 语法；新版可能提示弃用警告，应以实际服务器
版本及语法测试结果为准。所有共享 443 监听必须使用一致协议参数。

部署动作不在本轮授权内。得到部署授权后，还需对完整配置执行 `nginx -t`，再验证主域、www、
HTTP 跳转、ACME、CMS、页面/API、错误响应、证书链及 HTTP/2 协商；本文件不包含安装或重载执行器。

## HSTS 分阶段观察

| 阶段 | max-age | 进入条件 |
| --- | ---: | --- |
| 初阶段候选 | 604800（7 天） | 主域和 www 证书、HTTPS 跳转、续期和告警验证完成 |
| 后续阶段 | 2592000（30 天） | 生产观察确认 HTTPS、续期和告警持续正常后单独批准 |
| 长期阶段 | 31536000（1 年） | 再次评估恢复能力、证书续期与长期维护后单独批准 |

本轮不添加 `includeSubDomains` 或 `preload`，也不向预加载列表提交域名。
这避免未经核验的子域被连带强制 HTTPS。七天候选并不承诺消除所有“强 HSTS”审计提示，
长期缓存和子域覆盖须经过后续单独评估。

HSTS 会被浏览器记住。撤回候选文件或回退 Nginx 并不能立即清除浏览器已缓存的策略；
需要继续提供有效 HTTPS，必要时通过 HTTPS 返回 `max-age=0`，且只有重新访问的客户端才会更新。
