# CMS 内容韧性修复验证

## 范围

- 首页核心数据、服务、案例与 FAQ
- 关于页仓库节点与单例内容
- 服务专题页与全站联系信息的部分字段缺失
- Directus 新增案例在首页弹窗中的展示

## Red

先补充失败测试，复现以下问题：

1. Directus 不可用时，首页统计、服务、关于页仓库与案例列表为空。
2. Directus 返回旧统计值时，首页重新展示未审核口径。
3. FAQ 请求成功但返回空数组时，整组 FAQ 消失。
4. Directus 新增、但本地静态清单未知的案例无法生成首页弹窗数据。
5. 服务页、关于页或全站设置记录存在但字段为空时，空字段覆盖审核后的默认内容。

失败证据由以下测试给出：

- `tests/unit/directus.test.ts`
- `tests/unit/directus-content.test.ts`
- `tests/unit/home-case-details.test.ts`
- `tests/e2e/cms-fallback.spec.ts`

## Green

- 关键集合在请求失败或返回空集合时使用审核后的本地降级内容。
- 首页八项结构化公开指标始终使用审核口径，CMS 继续负责说明文字。
- 首页案例弹窗数据由当前案例集合生成，新增 CMS 案例不再成为无响应链接。
- 单例页面按字段降级，保留 CMS 已填写内容，并补齐空字段。

## 浏览器验证

- 首页：1440×900 与 430×932 逐屏滚动，无横向溢出、隐藏动画、坏图、脚本错误或页脚截断。
- 核心页面：`/product`、`/about`、`/cases`、`/news`、`/senlinqikan`、`/contact` 完成桌面与移动端巡检。
- 仓配服务：导航中的 9 个专题页完成桌面与移动端巡检。
- 当前 CMS 新增的茵曼案例可在首页打开弹窗，并同步更新独立详情 URL。
