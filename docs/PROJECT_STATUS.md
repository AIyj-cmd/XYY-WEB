## 发布边界

本次先发布到 `wz.tomatopia.top`。以下条件全部满足前，不启用 `56xyy.com` 重定向：

1. DNS 指向目标服务器；
2. 目标服务器签发并安装正式域名证书；
3. Nginx 正式配置通过 `nginx -t`；
4. `PUBLIC_SITE_URL`、`PUBLIC_DIRECTUS_URL` 与 CMS `PUBLIC_URL` 同步；
5. canonical、robots、sitemap、表单与 CMS 健康检查通过。

迁移配置草案：`deploy/nginx-56xyy.conf`。
