# 第 1–5 期白皮书转换复核记录

任务：`XYY-20260908-05` Phase2-A。本文只记录本地源图、缓存 OCR 与 HTML 数据间的转换边界；不代表线上发布或对原刊事实的再确认。

## 共同来源与方法

- 源 PDF：`public/senlinqikan/pdf/1.pdf` 至 `5.pdf`。五本 PDF 的正文都是图像；每页可提取的原生文字仅为网页地址、浏览器打印时间或页码，不能当正文。
- OCR 输入：`output/whitepapers-ocr-layout/issue-01` 至 `issue-05` 的 PSM3 行级 JSON 与 PNG。转换器只在 `scripts/whitepapers/early/early_layout.py` 的明确正文矩形读取，按该表的阅读顺序而非全局 y 坐标排序。
- 第 1 期和第 2 期的可读正文已按原图人工核对错字、断行和段落，不将文章改写为摘要；校正文本保留在同一显式 region 配置的 `verified_paragraphs`，可随 `convert_early_issues.py` 重生成。
- 每次转换先以当前 PDF 的 SHA-256 校验 `manifest.json`、每个 PSM3 行级缓存的 `physicalPage`、`side: full` 和哈希；任一不匹配即失败，不会用旧 OCR 生成新 PDF 的页面。
- 本次保留的 PNG 都是照片、列表或图表局部，未将整页、整半页或正文截图用作阅读页内容。
