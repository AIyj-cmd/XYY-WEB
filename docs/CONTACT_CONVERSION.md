# 官网咨询来源与服务预选

16 个服务详情页的 hero、bottom、floating 及既有 body 咨询入口会携带受控 `from` 和 `entry` 参数前往中英文联系页。联系页仅接受一个已知的来源页和入口组合，并在服务下拉框中完成 SSR 预选；直接访问、未知来源或重复参数不会预选服务。

用户可在表单中自行改选服务。中英文切换会保留有效的来源参数；无 JavaScript 时，入口链接和服务预选仍可用。

联系页另有原生 GET 的“按需求选择服务”：仅接受固定的 `need`（电商发货、门店补货、退货质检、商品整理、直播履约）和 `region`（不限、华东、华南）枚举。页面只在两个参数各出现一次且均有效时显示建议，并以同一受控映射预选表单服务；与既有 `from`/`entry` 来源映射冲突时不预选。案例详情使用受控 `case` slug；联系页仅在当前 CMS/审核回退解析结果仍包含该案例时显示案例语境，CMS 成功空结果不会复活静态案例内容。填写提纲必须由用户点击插入，保留既有文字、阻止重复和超过 1200 字时不修改输入。

移动实验室配置位于 `lighthouserc.mobile.cjs`，包含首页、产品、中英文联系页的 390×844 移动仿真；可用 `npx lhci autorun --config=lighthouserc.mobile.cjs` 单独运行。结果是实验室基线，不代表真实用户指标。
