## 整体设计

页面围绕“仓库在哪里 → 可以处理哪些订单 → 多仓如何配合 → 发货与费用 → 咨询”展开。

沿用白色、极浅暖灰 `#F8F8F6`、黑色标题、橙色重点和按钮。通过背景块、文字大小与留白分组，不使用装饰性横竖分隔线。功能性的键盘焦点轮廓保留。

与华南页保持配色、字体和圆角一致；华东采用上方标题配宽幅视频、三仓平级展示、左右错落的业务组合、简洁库存说明和双栏服务信息，形成自己的阅读节奏。

- 内容最大宽度约 1280px；1440px 桌面左右留白约 80px，手机左右 20px。
- 桌面主张字号约 64–80px，服务名称约 32–40px；各区域 H2 约 48–64px，仓库标题同级。手机主张约 36–44px、H2 约 30–36px，按宽度自然换行。
- 正文 15–16px、常规字重、1.8 左右行高；仓库地址完整换行，避免大段加粗。
- 区域间距约 88–112px，手机约 56–72px；按内容确定高度，不统一锁定满屏。
- 视频桌面 32px、手机 24px 圆角。保留现有干净仓库视频，静音自动循环，无控制条，维持 16:9，不加遮罩或视频上文字。

## 七个区域逐一设计

### 01 首屏：先讲清楚华东服务

**标题草案**

华东鞋服云仓

让发货，更贴近你的市场

**简介**：上海、昆山、合肥多仓布局，支持电商发货、门店补货与退货质检。

**布局**：桌面上方左侧是有大小层级的标题，右侧是短简介和橙色“咨询华东仓配”按钮；下方横向放置宽幅视频。上海、昆山、合肥以浅灰小胶囊靠近标题展示，不再做视频右侧竖栏。“查看仓库分布”作为轻量页内链接。

**手机**：标题、简介、城市胶囊、按钮、视频依次排列。首屏不放费用、时效和长篇合作条件。

### 03 一份库存，服务不同订单：错落的业务组合

**标题**：一份库存，服务不同订单

桌面左侧较宽的电商发货区域，右侧上下排列门店补货与退货质检。用区域尺寸与留白表现业务关系，避免重复华南三列业务版式；不使用表格、连接线或重复的介绍段落。

| 业务     | 对外文案草案                                               | 展示重点                                                                         |
| -------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 电商发货 | 从订单接入、拣货复核到打包出库，为华东订单安排仓配服务。   | 较大的主区域；天猫、京东、拼多多、抖音电商、快手等已有平台信息使用轻量文字标签。 |
| 门店补货 | 按门店整理货品，支持整件发货、拆零分拣与补货配送。         | 右上区域，短说明加三项服务词。                                                   |
| 退货质检 | 各仓均可处理退货质检，根据商品状态安排后续处理与二次上架。 | 右下区域；需修复的商品另行安排，不暗示每仓都有修复车间。                         |

手机按电商、门店、退货顺序单列阅读。现有退货时效若保留，从公开指标来源读取，并明确适用商品和服务条件，不扩大为所有退货均在固定时间修复完成。

### 04 多仓库存，一起管理：把系统能力讲成人能理解的服务

**标题**：多仓库存，一起管理

**主句**：华东与华南库存统一查看，根据订单地区和约定规则安排发货仓库。

桌面左侧主张与短说明，右侧用三个开放式文字分组：“统一看库存”“按规则发货”“跟进补货与对账”。取消 OMS 桥接图、仓库连线和节点框，也不制作未经证实的实时系统界面。

手机标题与三个分组顺排。发货安排取决于客户库存及约定规则，不宣称所有华东订单自动从上海仓出库。

### 05 发货时间清楚，费用提前说明

两块并列的浅灰圆角信息区域，分别回答“什么时候发”“费用怎么计”，不再使用四项大数字加竖线。

**发货安排**：集中展示现有“18:00 前截单、符合条件的订单当日 24:00 前发出”，具体数值继续取自公开指标。说明发出时间和送达时间的区别；“华东主要城市参考次日达”只在适用范围内展示，实际送达结合收货地址和承运线路说明一次。

原五组配送城市索引取消独立大区。江苏、浙江、安徽、福建及上海等现有配送信息归入此处或 FAQ，明确这是配送目的地，不是仓库清单；不逐城市贴上统一次日达承诺。

**费用说明**：系统使用费不收；接口实施、定制及增值服务费用另行说明。仓储和作业费用结合货品、库存与订单需求报价。避免把“不收系统使用费”扩大为全部系统对接免费。

手机两块上下排列，条件说明靠近对应内容，不做满屏免责声明。

### 06 常见问题：保留有用解释，降低阅读负担

**标题**：关于华东仓配，你可能还想了解

使用紧凑的浅灰圆角折叠项，以留白区分，取消通栏细线。采用原生可键盘操作的展开交互，不要求 JavaScript 才能阅读。

| 问题                           | 回答范围                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------ |
| 华东仓库在哪里，适合哪些需求？ | 上海青浦仓、昆山花桥仓、合肥联亚仓；对应电商、门店补货、退货需求。完整地址在上方直接可读。 |
| 发货到华东一般需要多久？       | 区分出库与送达；保留适用的截单安排、参考时效与收货地址/线路条件，去掉“核验口径”等词。      |
| 华东和华南仓库可以一起使用吗？ | 统一查看库存，按约定规则分仓发货、补货及对账，不写死城市路由。                             |
| 大促期间如何安排仓储和发货？   | 提前沟通库存、订单峰值、人员与作业安排；不增加未经确认的面积、产能和绝对承诺。             |

手机标题及回答自然换行。FAQ 正文与搜索结构化信息保持相同内容。

### 07 咨询收尾：用一件容易开始的事结束页面

**标题**：聊聊你的华东仓配需求

**说明**：告诉我们货品类型、订单去向和补货节奏，一起安排合适的仓库与服务。

简洁居中的收尾区域，保留本地团队沟通能力，用橙色“咨询华东仓配”按钮连接现有联系页。案例及返回服务列表作为次级入口，不新增表单或外部动作。手机按钮可舒适点按，不堆叠重复说明。
